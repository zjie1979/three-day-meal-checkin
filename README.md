# 三日轻记

可在 iPhone Safari 添加到主屏幕的公开静态 PWA，无登录、无后台、无分析统计。

## 用户确认的三日安排

1. 第一天：正常均衡饮食，晚饭后停止进食。
2. 第二天：白天5杯自制水，晚餐吃一顿约500大卡；5杯水各自独立打卡。未提供配方和容量，不预设零热量。
3. 第三天：恢复正常均衡饮食，不用补偿性多吃或再禁食。

这是记录用户所选安排的工具，不是统一临床方案或个人医疗处方。500大卡不是越低越好；是否适用应先咨询专业人员。未成年人、孕哺期、有进食障碍史者不应使用断食方案。糖尿病、使用降糖药或其他疾病者需要医生评估；不适时应停止，不为完成打卡硬撑。没有不掉肌肉、不会低血糖、优先减内脏脂肪或特定减重幅度的承诺。

## 功能

- 今日：短首页，仅显示当前阶段和操作入口；开始计划、打卡归档、自制水、饮食热量、体重感受均为独立短页面。
- 自制水：第二天5个独立勾选状态，支持取消勾选并保留刷新后的记录，不要求喝完才能归档。
- 热量：自制水、晚餐及其他分类记录；全天热量与晚餐小计分开，不默认自制水零热量。食物明细每页4条。
- 三日计划：一次显示一天，用三天切换按钮查看，不堆叠三个长卡片。
- 记录：每页3轮计划；每轮、每天和更正记录分别独立查看，备份也有单独页面。
- 说明：菜单链接到健康、安装、隐私和布局四个独立短页。
- 沿用原存储 key 与 schema 1；旧记录补充默认水杯状态和未分类餐次，不删除旧打卡、食物、体重及备注。
- 固定头部和底部导航，只有内容区上下滚动；16px输入字号，viewport、手势及触摸策略限制页面缩放。iOS辅助功能或浏览器设置仍可能覆盖网页的限制，不保证所有系统级放大均被阻止。
- 一轮结束后不会自动循环。原始帖是每周选一次轻断食，不应将本工具理解为每三天反复断食。
- 打卡表示如实记录，既可记录按计划完成，也可记录已调整或停止；不奖励空腹时长或极低热量。

## 隐私与迁移

源码公开，但用户输入只写入当前浏览器 localStorage（`threeDayMealCheckin.v1`），没有上传接口。清除网站数据、更换设备/浏览器/域名可能丢失或隔离数据。可导出 JSON 备份；分享备份前注意其中可能有个人饮食和体重记录。

## 安装

Safari 打开正式地址 → 分享 → 添加到主屏幕。微信内请先选“在 Safari 中打开”。首次联网加载后支持离线读取已缓存页面；不要把离线缓存视为备份。

## 本地运行

在此目录启动任意静态 HTTP 服务，无需安装依赖或构建。GitHub Pages 使用 main 分支根目录。
